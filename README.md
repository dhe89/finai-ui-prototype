
# FinAI UI Prototype — No LLM

Prototype khusus untuk mengecek layout/UI FinAI tanpa LLM dan tanpa database.

## Isi
- `app.py` — Streamlit app dengan UI dashboard
- `requirements.txt` — dependency minimal

## Fitur UI
- Sidebar kiri
- Dashboard Kinerja
- Laporan Keuangan
- Rincian Data
- Setting Parameter
- AI Assistant di kanan
- Chat simulasi tanpa LLM
- Responsive layout

## Deploy gratis
Gunakan Streamlit Community Cloud:
https://share.streamlit.io/

Hubungkan GitHub → pilih repository → `app.py` → Deploy.

Tidak membutuhkan API key atau model AI.
